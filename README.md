# Selenium TestNG Maven Framework — GitHub Actions

A UI test automation framework built with **Java 25, Maven, Selenium WebDriver 4, TestNG, and the Page Object Model (POM)**. This project includes a GitHub Actions CI/CD workflow (`selenium-ci.yml`) to automate test execution.

## Tech Stack

* **Java 25** — Programming language
* **Maven** — Build and dependency management
* **Selenium WebDriver 4** — Browser automation
* **TestNG** — Test execution and assertions
* **Page Object Model (POM)** — Maintainable and reusable test architecture
* **Google Chrome** — Browser for local test execution
* **GitHub Actions** — Continuous integration and automated test execution

## Prerequisites

Before running the tests locally, ensure you have the following installed:

* JDK 25
* Apache Maven 3.8 or later
* Google Chrome
* Git

## CI/CD

This project uses GitHub Actions to run automated tests through the `selenium-ci.yml` workflow, helping verify test results on pushes and pull requests according to the workflow configuration.
